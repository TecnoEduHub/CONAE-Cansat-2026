# Restricciones técnicas

Las restricciones técnicas más importantes que condicionan el diseño son:

- **Misión primaria:** el CanSat debe realizar durante el descenso un *sondeo atmosférico midiendo presión y temperatura*.

- **Dimensiones del CanSat:** el contenedor debe cumplir estrictamente:
	* Forma cilíndrica.
	* **70 mm de diámetro.**
	* **150 mm de longitud total (sin contar el paracaídas).** 

- **Peso máximo:** **250 gramos máximo**, incluyendo toda la carga útil. 

- **Sistema de descenso:** debe disponer de un sistema de descenso blando, normalmente un paracaídas. 

- **Alimentación:** debe utilizar baterías o pilas comerciales aprobadas para uso comercial. 

- **Electrónica:** puede utilizar la electrónica provista por CONAE de manera opcional. Para la misión secundaria debe ser compatible con dicha electrónica. 

- **Geometría exterior:** no puede haber:
	* antenas rígidas,
	* tornillos sobresalientes,
	* sensores,
	* soportes,
	* ni ninguna otra protuberancia que sobresalga del cilindro. 

- **Materiales permitidos:** se pueden utilizar materiales reciclables para el contenedor. No se aceptan materiales:
	* tóxicos,
	* contaminantes. 

- **Misión secundaria: ** la misión secundaria es opcional pero puntúa favorablemente. Para esta edición el objetivo propuesto es *capturar imágenes o video durante la liberación, apogeo y/o descenso.* 

- **Prohibiciones:** no se aceptan:
	* explosivos,
	* productos químicos peligrosos,
	* mecanismos que puedan afectar el despliegue,
	* mecanismos que comprometan la estabilidad del cohete,
	* experimentos con animales. 

- **Validación:** durante el desarrollo deberán demostrar mediante pruebas que el diseño es viable y cumple dimensiones, peso e integración antes de ser seleccionados para el lanzamiento.
